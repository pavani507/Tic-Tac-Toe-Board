# React + TypeScript + Vite




React Tic-Tac-Toe

A classic, type-safe 3×3 Tic-Tac-Toe game built using React, TypeScript, and Vite. This application features a real-time tracking scoreboard, automated win and draw evaluations, and a clean, responsive layout.



Features

• 3 × 3 Game Board: Interactive, grid-based layout. Empty cells lock permanently as soon as a player claims them.
• Turn Management: Supports local alternating turns between Player X and Player O with clear, visual tracking indicators.
• Win Evaluation Engine: Instantly evaluates standard horizontal, vertical, and diagonal lines. Highlights winning rows on completion and locks additional movements.
• Draw Conditions: Automatically verifies and captures a stalemate condition when all 9 cells are full without matching lines.
• Persisting Scoreboard: Tracks Player X scores, Player O scores, and running Draw counts over your active play session.
• Session Resets: Clear your board and current game state with a single click while preserving your running match records.
